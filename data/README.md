# Data directory

Do not commit unverified political verdicts as facts.

Each imported primary source should preserve:

- canonical source URL;
- archived URL when available;
- publisher;
- publication date;
- access date;
- exact quotation;
- page/section/timestamp;
- content hash;
- extraction notes.

The demo UI intentionally contains no substantive political verdicts. Real records should enter through a reviewed ingestion workflow.
